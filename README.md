# Feshchuk — AI-Driven Cyberpunk Portfolio

Персональный сайт-портфолио уровня Middle+/Senior Fullstack-разработчика с интегрированным AI-ассистентом. Строго тёмная киберпанк-тема.

## ✨ Возможности

- **Портфолио** — проекты в Bento Grid, рендеринг README из GitHub, лайки и просмотры
- **Технический блог** — Markdown (таблицы, код, изображения), озвучка статей (TTS)
- **AI-ассистент** — RAG (pgvector), Function Calling, стриминг ответа (SSE), голосовой ввод (STT) и озвучка (TTS)
- **Киберпанк UI** — неоновые акценты, glassmorphism, анимации Framer Motion
- **i18n** — RU / EN

## 🛠 Стек

## 🚀 Быстрый старт (разработка)

1. Скопировать и заполнить переменные окружения:
   ```bash
   cp .env.example .env
   # Внести: POSTGRES_PASSWORD, ROUTERAI_API_KEY, CONTEXT7_API_KEY и т.д.
   ```

2. Запустить все сервисы:
   ```bash
   docker compose -f docker-compose.dev.yml up -d --build
   ```

3. Применить миграции (при первом запуске):
   ```bash
   docker compose -f docker-compose.dev.yml exec backend python manage.py migrate
   ```

4. Создать суперпользователя для админки:
   ```bash
   docker compose -f docker-compose.dev.yml exec backend python manage.py createsuperuser
   ```

5. Открыть:
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8000/api/
   - Админка: http://localhost:8000/admin/

## 🤖 AI-агент

AI-ассистент использует:
- **RAG** — векторные эмбеддинги README проектов и статей (pgvector), top-3 retrieval
- **Function Calling** — `get_project_stats`, `list_projects`, `list_blog_posts`, `search_blog_posts`, `get_blog_post`, `activate_module`, `fetch_context7_docs`
- **Память** — история диалога хранится только в Redis (до 16 сообщений), автоматически удаляется в пределах 4 часов от последнего действия; персональные данные маскируются до отправки в LLM
- **Стриминг** — ответ приходит SSE-потоком по мере генерации: первые слова за ~1–3 с
- **Context7** — доки стека каждого модуля подгружаются в промпт автоматически (темы — в таблице ниже); доки смежных библиотек (CORS, rate limiting, кэширование) агент запрашивает сам по ходу ответа
- **Голос** — Web Audio API → STT (Whisper turbo) → LLM → TTS (Gemini); голос сопровождает ответ по мере генерации (кусочный синтез на лету)

Celery задачи:
- `sync_project_readme` — скачивание README из GitHub + регенерация эмбеддингов
- `generate_post_embeddings` — эмбеддинги для статьи
- `sync_all_projects_readme` — периодический синк (ежедневно)

## 🔒 Безопасность и приватность (152-ФЗ)

- **PII-маскирование** — телефон, email, паспорт, СНИЛС, ИНН и номера карт заменяются плейсхолдерами ДО отправки в LLM и ДО сохранения; персональные данные не покидают периметр сервера
- **Хранение диалога** — только Redis, автоудаление в пределах 4 часов от последнего действия; в PostgreSQL история не пишется
- **Право на удаление** — кнопка «Очистить диалог» удаляет сессию и историю на сервере (`DELETE /api/chat/session/`)
- **Анонимная аналитика** — лайки/просмотры: солёный хэш IP в Redis, TTL 24ч; без регистрации и форм сбора ПДн
- **Rate limiting** — Nginx (30 r/s API, 5 r/s AI-эндпоинты) + DRF по IP: чтение 2000/час, запись 120/час, чат и STT 30/час, TTS 120/час
- **Суточный бюджет LLM** — глобальный circuit breaker на расход RouterAI (защита от распределённого флуда с разных IP): счётчики запросов и токенов в Redis на сутки, при исчерпании чат отвечает 429 до конца UTC-суток
- **Политика приватности** — страница `/privacy` (RU/EN)
- Cookie-баннер для Яндекс.Метрики (запланировано)

## Обновление контента (seed_portfolio)

Команда `seed_portfolio` идемпотентна — можно запускать сколько угодно раз.

```bash
docker compose -f docker-compose.dev.yml exec backend python manage.py seed_portfolio
```

### Что делает

1. **Проекты (GitHub)** — перечисляет все публичные не-форк репозитории `Inna949Festchuk` через GitHub API, скачивает README и превью. Новые репозитории подхватываются автоматически.
2. **Статьи (Хабр)** — парсит страницу автора `habr.com/ru/users/dilmah949/articles/`, скачивает контент (HTML → markdown с картинками) и обложки. Новые статьи подхватываются автоматически.
3. **RAG-эмбеддинги** — генерирует vector embeddings для AI-ассистента (pgvector).

### Как пользоваться

| Действие | Результат |
|----------|-----------|
| Отметить «Избранное» в Admin | Проект появится на главной |

## 🗣 AI-ассистент: модули и голоса

AI-ассистент — это **PRIME COORDINATOR**, «дирижёр» портфолио: встречает пользователя по умолчанию, отвечает на общие вопросы и маршрутизирует запросы к четырём специальным модулям. У каждого модуля — свой системный промпт (SKILL) и голос TTS.

Активный участник диалога определяется контекстом:

- чат, открытый со страницы модуля (кнопка «ПОГОВОРИТЬ СО МНОЙ»), закрепляется за этим модулем;
- упоминание имени модуля в тексте переключает на него (в любом регистре и языке);
- вопрос по стеку модуля (ключевые слова: «бэкенд/Django/PostgreSQL/Celery», «безопасность/Django/152-ФЗ», «нейросети/RAG/векторы/LLM», «фронтенд/React/Next/UI/вёрстка») передаёт диалог этому модулю;
- слово «пока!» / «bye!» / «Neural Assist» / «помощник» / «assistant» возвращает диалог к PRIME COORDINATOR;
- «туманная» формулировка без ключевых слов («позови того, кто делает сайт красивым») — решает сам координатор: он вызывает нужного модуля инструментом `activate_module`, и ответ приходит уже от нового участника.

| Кто | Зона | Голос | Доки Context7 |
|-----|------|-------|---------------|
| PRIME COORDINATOR (дирижёр) | общие вопросы, навигация, маршрутизация | Puck (мужской) | — |
| HYPER DRIVE | бэкенд: Django, DRF, PostgreSQL, Redis, Celery, API | Enceladus (мужской) | Django 5 |
| QUANTUM SHIELD | безопасность: rate limiting, CORS, CSRF, HTTPS, 152-ФЗ | Charon (мужской) | Django |
| NEURAL SYNC | AI: RAG, pgvector, LLM, Function Calling, STT/TTS | Zephyr (женский) | LangChain |
| OMNI VISION | фронтенд: Next.js, React, TypeScript, Tailwind, UI/UX | Aoede (женский) | Next.js |

Ключевые слова стека хранятся в БД и редактируются в Django Admin (AI-агент → модули → поле «Ключевые слова стека») без правки кода.

Темы доки (Context7) меняются в `.env` — `CONTEXT7_MODULE_TOPICS`, JSON-словарь «модуль → тема» (например `CONTEXT7_MODULE_TOPICS={"neural-sync": "LlamaIndex"}`). Значение задаётся только для нужных модулей, остальные оставляют темы по умолчанию. После правки `.env` — пересоздать контейнер: `docker compose -f docker-compose.dev.yml up -d --force-recreate backend`.

Подводки:

- Имена модулей пишутся латиницей и работают в любом языке диалога: «привет neural sync» и «hello NEURAL SYNC».
- Смена участника не бывает молчаливой: если роутер или агент передаёт диалог другому модулю, новый участник первым предложением объявляет передачу («это моя компетенция, координатор передал диалог мне — я …»); возврат к дирижёру — с кратким анонсом.
- Возврат к координатору срабатывает на отдельное слово «пока»/«bye» — «покажи…», «пока не…» диалог не переключают.
- Голос и ключевые слова модуля меняются в Django Admin (AI-агент → модули) и действуют немедленно.
- Речь держится в языке интерфейса: голос фиксируется параметром языка запроса, а перед синтезом из текста убираются английские пояснения в скобках — насыщенные терминами ответы читаются по-русски.

### Замеры: скорость и качество ответа (2026-11-18)

Чат работает с выключенным «мышлением» LLM (reasoning off). Живой A/B-тест на `qwen3.5-plus` — две самые сложные задачи агента:

| Задача | Reasoning ON | Reasoning OFF | Результат |
|--------|--------------|---------------|-----------|
| Туманная маршрутизация: «позови того, кто делает сайт красивым» | 11,2 с / 0,134 ₽ | 1,3 с / 0,018 ₽ | Одинаково верно: переключение на OMNI VISION |
| Синтез по контексту: «какой проект сложнее по бэкенду и что перенести в другой?» | 20,3 с / 0,238 ₽ | 7,2 с / 0,081 ₽ | Одинаковый вывод; без «мышления» ответ конкретнее |

**Вывод:** для маршрутизации и ответов из контекста качество не страдает — режим без «мышления» в 3–9 раз быстрее и в 3–7 раз дешевле. «Мышление» нужно для длинных логических цепочек и математики, которых в задачах портфолио-бота нет.

Ответы стримингуются (SSE): на длинном ответе (800 токенов) текст начинается появляться через ~1,2 с вместо ~13,5 с ожидания полного ответа. Озвучка потоковая: законченные предложения синтезируются на лету — голос сопровождает текст по мере генерации и читает ответ целиком.

Режим и длина ответа настраиваются в `.env` без правки кода: `ROUTERAI_LLM_REASONING_ENABLED`, `ROUTERAI_LLM_MAX_TOKENS`.
